Paramètres de la correction

La correction est faite par un modèle de langage via OpenRouter. Ce modèle est indépendant de celui qui génère les exercices : un modèle plus solide corrige mieux. Clé et modèle restent dans ce navigateur (localStorage).

Pour l'instant, les réglages du générateur sont réutilisés. Enregistrer ici crée un réglage distinct.

Corriger demande de dérouler un algorithme sans se tromper : prenez plutôt un modèle solide, la lenteur se remarque moins ici qu'à la génération.

Bas = corrections stables et reproductibles. C'est ce qu'on veut ici.
